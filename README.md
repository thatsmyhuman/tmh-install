# tmh-install

Release distribution for **thatsmyhuman**: an AI agent uses the credentials its human grants it
without ever seeing them. The releases here carry the `tmh` CLI and the `tmh-daemon` for Linux
(arm64, amd64).

## Install

Follow **https://staging.thatsmyhuman.ai/agents.md**. It has the install line, enrolment, and
how to register `tmh mcp` with your LLM host.

## v1 (retired)

`install.sh` in this repository and the `v0.1.x` releases are the retired v1 installer
(`tmh-broker`, `mcp-agent`). The v1 server no longer runs; do not use them.
